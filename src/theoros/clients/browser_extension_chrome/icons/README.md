# Extension Icons

The manifest references these toolbar icons:

- `icon-16.png` (16x16)
- `icon-32.png` (32x32)
- `icon-48.png` (48x48)
- `icon-96.png` (96x96)

These can be added later. The extension loads and works without them —
Firefox uses a default puzzle-piece icon for extensions that don't
provide custom icons.

When creating icons, use a simple distinctive glyph (an eye, a lens,
the Greek theta) on a transparent or dark background so it's visible
in both light and dark toolbar themes.
